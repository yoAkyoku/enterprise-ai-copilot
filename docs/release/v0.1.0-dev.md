# v0.1.0 Developer Preview release checklist (historical baseline)

This checklist records the original preview boundary. The current production
track is documented in `v0.2.0-production-track.md`; do not use this file alone
to determine current feature availability.

## Included

- Policy-checked Customer Service Agent order-status flow.
- Agent, Skill, MCP, Plugin and schedule validators.
- Review-gated local Plugin registry with integrity and rollback records.
- Deterministic scheduler with retry, pause, concurrency and idempotency
  semantics.
- FastAPI HTTP API with Bearer authentication in default mode.
- In-memory and SQLite audit adapters.
- Synthetic data, Docker packaging, CI and local validation commands.

## Not included

- Real ERP, model-provider or remote MCP credentials.
- Distributed worker queue, clustered locks or hosted multi-tenant operation.
- Memory/RAG ingestion, approval UI, sandbox process isolation and frontend UI.
- Production deployment, external identity-provider integration and E7 proof.

## Maintainer release gate

- [ ] Run CI on the tagged commit.
- [ ] Run secret and dependency scans on the final history.
- [ ] Build and install the wheel from a clean checkout.
- [ ] Confirm Docker Compose smoke test on a host with Docker.
- [ ] Replace `NO_COMMIT_YET` in `docs/validation/evidence-index.csv` with the
      final commit SHA.
- [ ] Confirm `LICENSE`, third-party notices and known limitations.
- [ ] Publish release notes with the exact supported scope.
