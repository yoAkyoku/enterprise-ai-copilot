# v0.2.0 production-track checklist

Status: implementation in progress. This document is a gate, not a claim that
production deployment has already occurred.

## Included in this track

- Tenant-scoped Web operations console served by the API.
- Image evidence upload, content validation, preview, deletion and audit.
- Pluggable pre-storage malware scanner boundary, ClamAV INSTREAM adapter and
  retention cleanup API.
- SQLite attachment metadata and restart-safe run records.
- Workspace-filtered audit reads.
- Signed HS256 JWT boundary for self-hosted production identity injection.
- OIDC/JWKS RS256 boundary with exact HTTPS host allowlisting and key rotation
  refresh on unknown `kid`.
- Fail-closed rejection of preview auth modes and synthetic providers in
  staging and production startup.
- Migration files for runs, audit events and attachments.
- Durable approval queue with expiry, scope, argument hash and one-time token
  issuance.
- Authenticated metrics and readiness endpoints with request ID propagation.
- SQLite backup utility with integrity verification; production backup/restore
  still needs execution against the target storage service.
- OpenAI-compatible Vision/OCR adapter with HTTPS host allowlisting, bounded
  response, timeout and explicit per-request external-processing consent.
- Redis-backed atomic rate limiting is selected when `AGENT_REDIS_URL` is set;
  production startup rejects the in-process fallback.
- S3-compatible object storage is available with server-side encryption and
  bounded reads; production startup rejects the local filesystem adapter.
- The tag workflow includes a fail-closed `scripts/release_gate.py` check for
  resolved checklist items, PASS/WAIVED evidence and commit-bound records.
